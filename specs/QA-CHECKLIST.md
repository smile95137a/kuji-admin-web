## 一、通用基礎行為

### 1-1 認證 / Session

| # | 測試項目 | Admin | StoreOwner | StoreEditor |
|---|---------|:---:|:---:|:---:|
| A01 | 正確 email + password → 登入成功，導至 `/home` | ✅ | ✅ | ✅ |
| A02 | 錯誤密碼 → 顯示錯誤訊息，不登入 | ✅ | ✅ | ✅ |
| A03 | 首次登入 `force_change_password=true` → 強制導至變更密碼頁 | ✅ | ✅ | ✅ |
| A04 | 變更密碼成功後 `force_change_password=false`，可正常進入後台 | ✅ | ✅ | ✅ |
| A05 | F5 重新整理 → session 靜默恢復，不登出 | ✅ | ✅ | ✅ |
| A06 | 關閉瀏覽器再開 → 需重新登入（sessionStorage 清除） | ✅ | ✅ | ✅ |
| A07 | Token 過期（401）→ 自動 refresh，原請求繼續 | ✅ | ✅ | ✅ |
| A08 | Refresh 失敗 → 清除 session，自動導至 `/login` | ✅ | ✅ | ✅ |
| A09 | 後端返回 403 → 清除 session，自動導至 `/login` | ✅ | ✅ | ✅ |
| A10 | 未登入直接開啟受保護路由 → 導至 `/login` | — | — | — |
| A11 | 已登入開啟 `/login` → 自動導至 `/home` | ✅ | ✅ | ✅ |
| A12 | 帳號 INACTIVE 狀態 → 登入被拒，顯示錯誤 | — | ✅ | ✅ |
